# Sample files

In order to test the program, a few MARC records in different formats are available
in this folder.

MARC use is widely spread across libraries from many different countries, which often
offer their records under open licenses and allow one to grab them by Z39.50 or SRU.

If you don't have a Z39.50 client installed, you might want to have a look at my [Z39.50-to-HTTP](https://github.com/corbin-c/web-z3950) binding.
This allow one to query Z39.50 servers from a HTTP endpoint, in order to get MARC records in a web context.
